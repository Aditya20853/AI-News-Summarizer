# AI News Summarizer

## About the Project
AI News Summarizer is a Python desktop application
that retrieves news headlines and generates short
summaries using Artificial Intelligence.

## Technologies Used
- Python
- Tkinter
- Google News RSS
- Requests
- BeautifulSoup
- Ollama
- Llama 3.2 3B

## Features
- Search news by topic
- Display news headlines
- Extract article text
- Generate AI-based summaries
- Copy generated summaries

## Installation

1. Install Python.
2. Install Ollama.
3. Download the model:

   ollama pull llama3.2:3b

4. Install dependencies:

   pip install -r requirements.txt

5. Run the application:

   python main.py
